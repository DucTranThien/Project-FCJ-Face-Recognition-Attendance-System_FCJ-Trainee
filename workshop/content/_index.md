# FCJ Face Recognition Attendance System

### Overview

In this workshop, you will learn how to build a complete face recognition attendance system using Amazon Rekognition, Flask backend deployed via Zappa to AWS Lambda, and a static frontend hosted on S3 with CloudFront. The system includes user registration with email OTP verification via SMTP, face indexing, and real-time attendance tracking with DynamoDB storage.
